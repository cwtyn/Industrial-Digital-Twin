## 🎨 设计定论 · SL / HE 跨高度层显示方案（复用 TC R/F 套路）

> 布局图当前已用 **y 行 = 高度** 表达（LT 低/中/高各占一行）。SL/HE 升降跨层，照 TC R/F 的显示层拆分手法制图，不改图模型。

**画法：拆成两个对齐半节点 + 竖直升降边**
```
 L1层 ── ...RB ────┬──── ...RB ──      ← 每层各占一行(y)
                    │ ▐█▓█            ← SL/HE 竖直件
                    │ ▐█▓█
 L2层 ── ...RB ────┴──── ...RB ──
```

| 要素 | 做法 | 复用 |
|---|---|---|
| 高低两段链 | 各自一行(y)，位上放 RB | 现状（LT 分层就是如此）|
| SL/HE 本体 | 拆两个**对齐半节点** `_L1/_L2`，同 x 不同 y | TC R/F 拆分套路 |
| 竖直边 | 两半节点间虚线/双箭头，标「升降 L1↔L2」 | TC 换向虚线 |
| SL vs HE | 不同的形状/颜色（剪式 vs 提升机） | 现有 node type SL/HE |
| 到位信号驱动 | 有 `DrPos` 类信号则 `positions` 驱动半节点颜色（在→绿/灰，不在→暗）| TC 机制现成 |
| HE 多层(>2) | 中间竖直脊柱，各层半节点向脊柱扇出 | 同规则展开放大 |

**优点**：信息准确编码高度、完全复用成熟代码、2D 边不交叉、到位状态照旧显示。
**明确不做伪 3D/等距分层**（无路径/状态增益、维护成本高）；2D 分层带即够。

- [ ] 实现时：半节点命名规则（提议 `{原节点}_L1/_L2`）、shape/颜色区分 SL 与 HE、到位信号点位表（仍按 TC 那样由 PLC/现场给定，不推导）。

## 🎨 设计定论 · 传输分类与制图规范（Line_4 起，2026-10-21 用户定夺）

**目标**：图要表达「车怎么被传过去」（方向/机制），不是「物理设备叫什么」；把传输方式从设备类型里解耦。

| 传输方向 | 机制 | 图上做法 | 是否有位置信号 |
|---|---|---|---|
| 横向（同滚床轴线）| 普通 RB | RB→RB 默认边，不额外建节点 | 有（车身号）|
| 纵向（跨行/跨链驳车）| **CP** 横移链 | 静态机制点 + 跨行边，只标"可纵向到此" | **无**，仅标注，不检测位置 |
| 纵向（跨链）| **TC** 横移车 | 同 TC R/F 拆分套路 | **有**（`DrPos` 等），可位置驱动 |
| 转向 | **TT** 转台 | 仅 90°/180°，按"滚床 + 更长耗时 + 可能额外出口"建模 | 无，不画角度 |
| 跨高度 | **HE**/SL | 半节点 + 竖直边（上一设计定论）| 有则驱动，无则静态 |
| 升降物理干涉消除 | **LT** | **Line_4 简化不画**，看效果，OK 再回头补 Line_1-27 | — |

**定夺要点（用户已拍板）：**
1. CP **不深究物理**：一个 CP 管 2+ RB、或 2 个 CP 组合——都不建模，只要 "RB1→RB2 横向、RB1→RB3 经 CP 纵向、RB3→RB4…" 的可达关系正确。
2. CP **无位置信号**（停靠靠所在 LT 的 RB 体现）→ 不检测位置，布局图仅**标注机制点**，不驱动颜色。
3. TT 只做 90°/180°：180°=普通滚床（时长不同）；90°=下一输送转向 + 可能多出口，仍是滚床，**传送时间更长**，不画旋转角度、无位置信号。
4. LT 不是传输机制节点，仅用于 CP 处消除物理干涉；Line_4 先不画。

**纯 LT 存车位（区别于 LT 工位）**：Line_4 整理中发现一类**纯 LT**——仅作临时存车（hold）、无加工，经 CP 传送。tag 规则 = **LT/LT 绑定**（X1=LT 代号、X2=LT 代号），例 `.L3L4_1C_1C205LT_1C205LT.SD…`（X1=X2=LT，就是"实为 LT 的纯 RB"写法）：

| 类型 | X1 | X2 | 用途 | 示例 |
|---|---|---|---|---|
| LT 工位（老） | LT 代号 | **RB** | 加工站 | `1A010LT_1A010RB` |
| **纯 LT 存车位** | LT 代号 | **LT** | 临时存车 | `1C205LT_1C205LT` |

- 纯 LT 存位照旧纳入**可停集合**、报车身号；对外按 hold 看待（can_park=True）。
- Line_4 骨架需把纯 LT 存位与其他可停位一并列出，tag 按 **LT/LT 绑定**（X1=X2=LT）生成。
